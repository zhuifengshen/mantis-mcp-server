# Mantis Workflow MCP 6.0.0

首个公开 Workflow MCP 版本，提供缺陷查询、上下文读取、修复与自测登记、延期/重开、备注、附件，以及按原操作编号核查和恢复的固定工作流。

## 安装

需要 Node.js 22.12+（22.x）、24.x 或26+。npm 包为 `@youcloud/mantis-mcp-server`，命令名为 `mantis-mcp-server`：

```bash
npm install --global @youcloud/mantis-mcp-server@6.0.0
```

也可下载本页 `.tgz` 安装包及 `.sha256` 校验文件，验证摘要后执行 `npm install --global ./youcloud-mantis-mcp-server-6.0.0.tgz`。安装生产依赖仍需要联网。

通过环境提供 `MANTIS_BASE_URL`、个人 `MANTIS_API_KEY` 和经项目核对的 `MANTIS_WORKFLOW_CONFIG`。Codex 等客户端的配置示例见 [README](https://github.com/zhuifengshen/mantis-mcp-server#readme)。

## 升级变化

- 默认13个工具；关闭/删除/版本管理扩展后共23个。旧通用修改工具迁移到明确业务动作。
- 真实写入使用 `operation_id` 和对象前置标识。主写入成功、后续失败时保留部分成功；未知写入不盲目重发。
- 仅支持本地 stdio，移除旧 HTTP 服务、本地语义搜索和模型下载。
- 40 MiB为本地文件政策，部署方仍需验证 JSON/Base64 编码后的请求体限额。

详见 [迁移说明](https://github.com/zhuifengshen/mantis-mcp-server/blob/v6.0.0/docs/migration-v6.md)及 [变更记录](https://github.com/zhuifengshen/mantis-mcp-server/blob/v6.0.0/CHANGELOG.md)。本页安装包在独立目录仅安装生产依赖后验证 stdio 握手及13/23工具；该验证不代表任何用户部署的真实写权限。
